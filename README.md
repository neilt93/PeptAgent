# PeptAgent

Work-in-progress LLM-orchestrated agent for therapeutic peptide design. Intended
stack: ESM-2 and ESMFold for sequence/structure, AutoDock Vina for docking,
conformal prediction for reliability estimates, and Pareto multi-objective
scoring. The working code currently lives in a private local repo and has not
yet been published here, so this GitHub repository is an empty shell.
